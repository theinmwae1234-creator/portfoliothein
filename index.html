Featured Project 01 / Electromechanical System

LIFTOFF — Smart Lift-Assist Cushion System

Assistive mobility prototype addressing sarcopenia-related sit-to-stand challenges through actuator-driven mechanical assistance, analog PWM control, H-bridge driving, MOSFET switching, and physical prototype testing.

SYSTEM ARCHITECTURE

ActuationLinear Actuator
MechanismScissor Linkage
PWM Source555 Timer
Logic LayerAnalog Comparator
DriveH-Bridge + MOSFET
ValidationLoad Testing

Problem Statement

1 in 7 adults in Singapore suffer from sarcopenia, leading to muscle weakness and difficulty in standing or walking. Existing aids often lack portability or require significant effort. This project proposes a portable assistive device that helps users stand up using a scissor-lift mechanism with ball-bearing linkage, driven by a linear actuator to provide smooth and stable lifting.

Featured Project 02 / Industrial IoT System

Industrial IoT Smart Farming Monitoring System

Create a system that can ease manpower resources and allow close real-time monitoring of medium/large scale vertical farming

SYSTEM ARCHITECTURE

Edge DeviceRaspberry Pi
DashboardNode-RED + Tailscale
Long RangeLoRaWAN
MessagingMQTT
Industrial BusModbus RTU
OutputPump Automation

Problem Statement

The government wants to achieve the 30 by 30 rule in Singapore, which is to be able to produce 30 percent of our nutritional needs by 2030. However, the current state of Singapore farming has a labour shortage problem and limited land which requires for the farmers to change the farming from traditional farming to hydroponic farming. Hydroponic farming is an agri-tech speed up the growing cycle of plants without compromising nutritional value, allowing Singapore to increase its production output with existing resources and without the need of soil. We can use technology and smart farming to overcome these problems and attract new young gen to join farming,because it will no longer always be under the sun; have remote access and data analysis, and be more sustainable.
